# Synqra

Synqra is a desktop workspace for running and coordinating your AI agents in one place.

## Download

Get the latest Windows installer from the [Releases page](https://github.com/aehng/synqra-releases/releases/latest) (`Synqra-Beta-<version>-x64.exe`).

Installed copies update themselves from this repository.

Website: https://synqra.info

This repository only hosts release installers. It contains no source code.
